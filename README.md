# Πρέφα — εγκατάσταση στο GitHub Pages

## Τι ανεβάζεις

Στον φάκελο `prefa/` της αποθήκης σου, όλα **στο ίδιο επίπεδο**:

```
prefa/
├── index.html                 ← αντικαθιστά το παλιό αρχείο
├── manifest.webmanifest
├── sw.js
├── icon-192.png
├── icon-512.png
├── icon-maskable-512.png
├── apple-touch-icon.png
└── favicon.png
```

Αν το παλιό σου αρχείο λέγεται `prefa.html`, σβήσ' το ή άφησέ το·
αυτό που φορτώνει στο `nvrionis.github.io/prefa/` είναι το `index.html`.

Τα ονόματα και οι θέσεις των αρχείων πρέπει να μείνουν ακριβώς έτσι —
το `sw.js` πρέπει να είναι δίπλα στο `index.html`, όχι σε υποφάκελο.

## Πρώτη φορά στο κινητό

1. Άνοιξε το `https://nvrionis.github.io/prefa/` στον Chrome.
2. Μενού ⋯ μέσα στην εφαρμογή → **Εγκατάσταση στην αρχική οθόνη**.
   Αν δεν εμφανίζεται, μενού του Chrome (⋮) → «Προσθήκη στην αρχική οθόνη».
3. Σε iPhone: Safari → κουμπί κοινοποίησης → «Προσθήκη στην αρχική οθόνη».

Μετά την εγκατάσταση δουλεύει και χωρίς ίντερνετ.

## Όταν κάνεις αλλαγές — ΣΗΜΑΝΤΙΚΟ

Κάθε φορά που ανεβάζεις νέα έκδοση, άλλαξε **μία γραμμή** στο `sw.js`:

```js
const VERSION = "v1";   →   const VERSION = "v2";
```

Χωρίς αυτό, τα κινητά συνεχίζουν να δείχνουν την παλιά έκδοση από την
τοπική μνήμη. Με αυτό, την επόμενη φορά που θα ανοίξει η εφαρμογή
εμφανίζεται κάτω μια μπάρα «Υπάρχει νέα έκδοση → ΑΝΑΝΕΩΣΗ».

## Αν κάτι κολλήσει

Chrome → Ρυθμίσεις → Ρυθμίσεις ιστότοπου → Δεδομένα ιστότοπου →
βρες το `nvrionis.github.io` και διάγραψε. Προσοχή: σβήνει και την
τρέχουσα παρτίδα, οπότε κατέβασέ τη πρώτα από το μενού.
